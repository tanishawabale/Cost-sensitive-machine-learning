# Cost-sensitive-machine-learning

**Predictive Maintenance Cost Analysis**

**Overview**

This project predicts machine failure using machine learning and evaluates the business cost of prediction errors. The focus is on reducing costly missed failures using cost-sensitive modeling and SMOTE for class imbalance.

**Models Used**

Random Forest (Baseline)

Random Forest (Class Weight)

Random Forest with SMOTE

**Conclusion**

The SMOTE model reduced false negatives, which lowered the overall business loss. Therefore, it provides a better solution for predictive maintenance compared to the baseline model.
